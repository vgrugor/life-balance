# Agent instructions

## Project

This project is a static, mobile-first PWA without a framework or application server. The interface is in Ukrainian. Data is stored in the browser's IndexedDB; Google Sheets is used only for manual backups through `apps-script.gs`. See `README.md` for user-facing behavior and setup instructions.

## Code map

- `src/index.html` and `src/styles.css` contain the markup and styles.
- `src/app.js` contains the main logic, IndexedDB access, planning, history, import, and export.
- `src/base-accordions.js` renders the task library by quadrant. It shares the DOM and IndexedDB with the main app.
- `src/sheets-guard.js` handles the Google Sheets buttons and intercepts their events before the handlers in `app.js`. Account for both files when changing backup behavior.
- `src/sw.js` manages the offline cache. `scripts/build.mjs` builds `dist/` and replaces `__BASE_PATH__` and `__APP_VERSION__`; `scripts/dev-server.mjs` serves the app locally.
- `.github/workflows/pages.yml` builds and publishes GitHub Pages using the repository base path.

## Data and compatibility

- IndexedDB `balance-quadrants-db` has `tasks`, `plans`, `logs`, and `settings` stores; its current version is `2`. When changing the schema, keep the version number in sync across `src/app.js`, `src/sheets-guard.js`, and `src/base-accordions.js`, and update migration logic in the first two files.
- JSON backups contain `schemaVersion`, `tasks`, `plans`, and `logs`. `settings` (the Web App URL and API key) remain local and are not exported. Coordinate format changes across JSON import, Google Sheets backup/restore, and `apps-script.gs`.
- Recurring tasks are suggestions. A `plans` record is created only after a user action. Completions are stored separately in `logs`.
- Plan dates use local `YYYY-MM-DD` values, while timestamps use ISO format. Preserve this distinction in calendar and history logic.
- Do not commit a real API key: `BACKUP_KEY` in `apps-script.gs` is a placeholder for a user's own deployment.

## Verification

- Requires Node.js 20+. Run locally with `npm run dev`, build with `npm run build`, and inspect the build with `npm run preview`.
- Run all tests with `npm test` after installing Chromium with `npx playwright install chromium`. This includes browser tests and mocked Apps Script tests. `.github/workflows/tests.yml` runs the same command on pull requests and pushes to `main` or `master`. For behavior changes outside those tests, manually check the relevant browser flow, including a reload with saved data. For PWA or path changes, also build with `BASE_PATH=/life-balance/ npm run build`.
- `dist/` is generated by the build; edit the sources in `src/`. When adding a static file, include it in `scripts/build.mjs` and, if it must work offline, in the asset list in `src/sw.js`.
