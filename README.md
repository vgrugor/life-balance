# Баланс справ

Mobile-first PWA для відстеження, куди йдуть сили між чотирма квадрантами:

- Я / Підтримка
- Я / Розвиток
- Світ / Підтримка
- Світ / Розвиток

Це не todo-list і не система оцінювання продуктивності. Застосунок лише показує розподіл уже відмічених справ за розмірами S, M, L.

## Можливості

- база справ із датою додавання, квадрантом, розміром і повторюваністю, включно з конкретними днями тижня;
- фільтр бази справ за квадрантом;
- планування на вибрану дату, за замовчуванням на завтра;
- повторювані справи показуються як пропозиції для планування, а не додаються автоматично;
- підказка балансу прямо під час планування;
- перегляд “Сьогодні” із запланованими справами;
- ручний порядок справ у межах дня та квадранта;
- історія з часом виконання та баланс за 3, 7, 14 і 30 днів;
- “нагадати пізніше”, щоб тимчасово прибирати неактуальні справи з бази;
- повний JSON-імпорт/експорт;
- CSV/TSV-експорт для Google Sheets;
- backup/restore через Google Apps Script Web App;
- локальне збереження URL application та API ключа для Google Sheets у браузері пристрою;
- offline-first після першого завантаження;
- без бекенду, сумісно з GitHub Pages.

## Локальний запуск

Потрібен Node.js 20+.

```bash
npm install
npm run dev
```

Після цього відкрий:

```text
http://localhost:5173
```

## Збірка

```bash
npm run build
```

Артефакт буде в `dist/`.

Для GitHub Pages base path можна задати явно:

```bash
BASE_PATH=/repo-name/ npm run build
```

## Деплой на GitHub Pages

1. У репозиторії відкрий `Settings -> Pages`.
2. У `Build and deployment` вибери `GitHub Actions`.
3. Запуш зміни в гілку `main`.

Workflow `.github/workflows/pages.yml` сам збере `dist/` і опублікує Pages. Base path підставляється як `/${repository-name}/`, тому застосунок працює в project pages.

## Google Sheets backup

Для GitHub Pages використовується Google Apps Script Web App, як окремий endpoint біля твого Google Sheet.

URL application та API ключ можна ввести на вкладці `Бекап`. Вони зберігаються тільки локально в IndexedDB конкретного браузера і не входять у JSON-бекап.

Налаштування:

1. Створи окремий Google Sheet для цього застосунку.
2. У Google Sheet відкрий `Extensions -> Apps Script`.
3. Встав код з `apps-script.gs`.
4. Заміни `BACKUP_KEY = "change-this-key"` на свій довгий випадковий ключ.
5. Обери `Deploy -> New deployment -> Web app`.
6. `Execute as`: себе. `Who has access`: anyone with the link.
7. Скопіюй Web App URL.
8. На телефоні у вкладці `Бекап` введи Web App URL у `URL application`, а ключ у `API ключ`.

Кнопка `Зберегти backup у Sheets` записує повний JSON backup у вкладку `backup`. Кнопка `Відновити з Sheets` завантажує останній backup і замінює локальні дані.

CSV/TSV експорт лишається як простий ручний варіант для перегляду даних у таблиці.
